# Test Kanban Board

This is a test board for demonstrating the kanban-md plugin functionality.

## Instructions

1. Open this file in Neovim
2. Run `:lua require('kanban-md').setup()` to initialize the plugin
3. Try the following commands:
   - `:KanbanNewCard` - Add a new card
   - Place cursor on a card below and try `:KanbanMoveCard`
   - Place cursor on a card and try `:KanbanCompleteCard`
   - Try `:KanbanStats` to see statistics
   - Try `:KanbanArchive` to archive old completed cards
